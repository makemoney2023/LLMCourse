# Music beds

Place **cleared / licensed** bed tracks here before production `music_caption` Shorts.

- Allowed extensions: `.mp3`, `.wav`, `.m4a`, `.aac`, `.ogg`
- Do not commit uncleared or copyrighted material
- `resolveMusicBed` picks a bed deterministically from `pack.id`
- Without beds, production mode throws; set `SHORTS_DRY_AUDIO=1` for a silent stub during local dry runs
