# Workshop Session 3 — Conversation, memory & shared work

**Modules:** 7–9 (`conversation-and-compaction`, `memory-systems`, `delegation`)  
**Duration:** 90 minutes  
**Outcome:** Learners can hand off cleanly, store trusted memory, and share agent work with clear ownership.

## Agenda

| Minutes | Activity |
|--------:|----------|
| 0–10 | Recap + horror stories of long threads |
| 10–30 | Module 7: continue vs restart decisions |
| 30–55 | Module 8: memory tier sorting + prune |
| 55–70 | Module 9: agent layers + specialist contract |
| 70–85 | Shared-workspace collision lab |
| 85–90 | Synthesis on the loop diagram |

## Demo script

1. Grow a messy thread with tool results and topic changes.
2. Write a handoff summary; open a fresh chat; continue successfully.
3. Show a bad long-term memory fact poisoning a new session; correct it.
4. Repair a collision caused by old rules, stale memory, and two editors.

## Pair exercise

Draft a workspace contract for two specialists. Name canonical sources, tools, approvals, edit boundaries, handoff, and merge owner.

## Take-home

Complete Modules 7–9. Reuse the workspace contract once before Session 4.
