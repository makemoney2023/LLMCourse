# Workshop Session 4 — Human craft, verify & capstone

**Modules:** 10–12 (`human-craft`, `verify-and-harden`, `capstone-lab`)  
**Duration:** 120 minutes  
**Outcome:** Each learner completes one end-to-end loop run on a real workflow.

## Agenda

| Minutes | Activity |
|--------:|----------|
| 0–15 | Spec writing warm-up + reverse prompting |
| 15–35 | Modes & approvals scenarios |
| 35–55 | Failure modes clinic + security habits |
| 55–100 | Capstone lab (configure → run → verify) |
| 100–120 | Retrospectives + team defaults discussion |

## Demo script

1. Take a vague stakeholder ask; reverse-prompt into a spec.
2. Run once without verify; show a subtle error.
3. Apply checklist; catch the error; update standing playbook.

## Capstone constraints

- Real workflow the learner owns
- Standing instruction + playbook + grounding + done checklist
- One measured before/after note (time, revisions, or error caught)

## Take-home

Publish team defaults (rules/skills/checklists) where the team will actually see them.
