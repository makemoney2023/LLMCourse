# Workshop facilitator notes: Capstone lab

**Workshop session:** 4  
**Module duration:** ~45 minutes (may extend full session block)  
**Session outcome:** Each learner completes one end-to-end loop run on a real workflow

## Purpose

Integrate all modules in a timeboxed real run; capture retros for team learning.

## Timing options

### In-room lab (~90 min total with Module 10)

| Segment | Minutes | Activity |
|---------|---------|----------|
| Scope | 10 | Exercise 1 pitches—facilitator rapid feedback |
| Configure | 15 | Exercise 2 silent work; office hours |
| Execute | 45 | Exercise 3 run; facilitators roam |
| Retro | 15 | 3–4 volunteers or breakout share |
| Close | 5 | Commit one team default from cohort insights |

### Async capstone

Assign Exercises 1–2 pre-session; use workshop for troubleshoot + retro only.

## Facilitator roles during execute

- **Scope police** — cut creeping workflows early
- **Loop coach** — ask "which node?" when stuck
- **Safety** — stop autonomous external sends; no real secrets
- **Verify enforcer** — pause before "done" until checklist runs

## Demo (optional kickoff)

Facilitator runs **mini capstone** (10 min): spec → attach one doc → draft → verify two claims → update one-line PROJECT note. Narrate each node.

## Discussion prompts (retro)

- "Which node would have saved you the most time if configured earlier?"
- "What will you remove from standing context tomorrow?"
- "What verify check caught something surprising?"
- "What team default should we adopt from today's retros?"

## Success criteria

Learner leaves with:

- Completed run (or documented blocker + fix plan)
- Written retro with keep/remove/next intent
- At least one durable artifact (checklist, rule, note)

## Materials

- Loop diagram (all nodes highlighted)
- Scope template from Exercise 1
- Timer visible for execute block
- Shared retro slide format (5 bullets)

## Post-course

Encourage **run #2 in one week** and share retro in team channel. Collect anonymized retros for internal course improvement.
