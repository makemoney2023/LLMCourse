# Workshop facilitator notes: Deep research

**Workshop session:** 1  
**Module duration:** ~20–25 minutes inside Session 1  
**Session reference:** `curriculum/workshops/session-01.slides.yaml`

## Purpose

Install the habit: research → cited markdown pack → then instructions/playbooks. Learners should leave knowing how Firecrawl-style tools (or equivalents) feed the context loop.

## Timing

| Segment | Minutes | Activity |
|---------|---------|----------|
| Hook | 3 | Show a project that started on vibes vs one with a BRIEF.md |
| Teach | 7 | Context pack file set; research vs chat |
| Live demo | 10 | Firecrawl/deep research → SOURCES.md → BRIEF.md |
| Exercise | 8 | Scope card + start sources list |
| Bridge | 2 | “Next we write instructions from the brief—not from memory.” |

## Demo steps

See Session 1 slide **Live demo — deep research pack** facilitator notes for the full script (Firecrawl search/scrape → markdown files → attach later).

## Discussion prompts

- Where have we written rules before we knew the domain language?
- What belongs in BRIEF.md vs raw crawl dumps?
- How do citations change trust in agent output?
