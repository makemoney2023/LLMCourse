# Facilitator notes — Conversation & compaction

**Workshop session:** 3  
**Module duration:** ~20 minutes inside Session 3  
**Session reference:** `curriculum/workshops/session-03.slides.yaml`

## Purpose

Install the habit: when the desk fills with tool dumps or the topic shifts, write a short handoff and restart. Learners should leave knowing continue vs restart — and what belongs in a handoff note.

## Timing (within parent workshop session)

| Segment | Minutes | Activity |
|---------|---------|----------|
| Hook | 3 | Horror story of a three-day chat that reused stale tool output |
| Teach | 5 | What piles up; good handoff parts; continue vs restart |
| Live demo | 12 | Messy thread → ten bullets → handoff → fresh chat |
| Exercise | 8 | Pair: write a handoff; peer continues from the note alone |
| Bridge | 2 | "Next we decide what sticks for later — memory tiers." |

## Demo steps

1. Grow a messy thread: draft a FAQ, paste a huge tool dump, then pivot mid-chat to a sales email.
2. Ask for ten bullets from the tool dump; drop the raw log from focus.
3. Write a handoff note live: Goal, Done checks, Locked choices, Sources, Do not, Open questions.
4. Open a fresh chat. Paste only the handoff (plus BRIEF.md if needed). Show that quality returns.
5. Contrast: continuing the polluted thread keeps old refund numbers in the new draft.

## Discussion prompts

- Where does your team currently skip this node?
- When did a long thread last "remember" something that was no longer true?
- What artifact should become a shared default after today (handoff template)?

## Pair exercise

Partner A writes a handoff for a real in-progress chat (or the sample thread). Partner B must continue the job from the note alone — no old chat. If B cannot, fix the handoff, not the model.
