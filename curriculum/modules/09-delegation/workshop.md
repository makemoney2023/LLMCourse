# Workshop facilitator notes: Delegation

**Workshop session:** 3  
**Module duration:** ~30 minutes  
**Closes Session 3**

## Purpose

Learners split mega-tasks, write delegation contracts, and spot unsafe parallelization—before quality cliffs force accidental serial work.

## Timing

| Segment | Minutes | Activity |
|---------|---------|----------|
| Teach | 8 | Overloaded thread vs specialists; brief anatomy. |
| Exercise 1 | 8 | Split mega-task; groups compare specialist count. |
| Exercise 2 | 10 | Write one full contract; peer review done criteria. |
| Exercise 3 | 7 | Safe vs unsafe rapid fire. |
| Close | 2 | Session 3 recap: compaction, memory, delegation. |

## Demo steps

1. Show one bloated transcript—note unrelated tool output.
2. Split live into research vs implementation briefs (two chats or subagents if available).
3. Show **unsafe** parallel edit collision (diagram or story)—fix with branches + integrator.
4. Return format demo: child returns 5 bullets + PR link, not raw logs.

## Discussion prompts

- "When did parallel agents help vs hurt?"
- "Who is merge owner on your team today?"
- "Which tasks must stay read-only for research agents?"
- "How does delegation interact with approvals (preview Module 10)?"

## Session 3 close

Three lenses on context: **shrink** (compaction), **persist** (memory), **split** (delegation). Preview Session 4: human craft and verify.

## Materials

- Mega-task text (Exercise 1)
- Delegation contract checklist on slide
- Module diagram (delegation branch highlighted)
