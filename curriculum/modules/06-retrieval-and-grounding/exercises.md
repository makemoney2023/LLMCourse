# Exercises

## Exercise 1: Pick sources for three task types
**id:** ex-1

For each task type, name the best source type and where it lives in your pack (if applicable): (a) a how-to question, (b) a number or policy claim, (c) a tone-only rewrite.

<details>
<summary>Answer key</summary>

Worked example:

| Task | Best source | Example |
|------|-------------|---------|
| How-to | Official docs section | SOURCES.md row "Admin guide §3 install" |
| Number / policy | Dated metrics or handbook | BRIEF.md limit line + SOURCES.md pricing page |
| Tone rewrite | Brand guide or wall tone rule | Wall rule "concise, no hype" — no fact cite needed |

How-to needs retrieve from docs. Numbers need retrieve plus quote. Tone may use wall rules only — but do not treat wall rules as proof for numbers.

</details>

## Exercise 2: Trim an overstuffed file pack
**id:** ex-2

Scenario: you attached five huge PDFs for one question: "What is the Basic plan CSV export rule?" List what you keep, what you remove, and what you attach instead from your one-page summary (BRIEF.md) or proof list (SOURCES.md).

<details>
<summary>Answer key</summary>

Keep: one handbook section (Export rules, §2.4) or SOURCES.md row linking the pricing page.

Remove from desk: four unrelated PDFs (onboarding, HR, security audit, old deck).

Attach instead: BRIEF.md "Plan limits" bullet + quote prompt: "Quote export rule from §2.4, then answer yes/no."

Worked answer shape: "Basic: no CSV export (handbook §2.4). Pro: CSV included." — teammate can open §2.4 and match the line.

</details>

## Exercise 3: Write retrieve-then-answer steps
**id:** ex-3

Write a six-step mini-playbook that forces lookup from BRIEF.md or SOURCES.md before answering a factual question. Include what to do if the fact is missing.

<details>
<summary>Answer key</summary>

Worked example:

1. Restate the factual question in one line.
2. Open the one-page summary (BRIEF.md) or the SOURCES.md row named in the ask.
3. Attach only the section that holds the answer.
4. Quote the exact line(s) in the reply.
5. Answer yes/no or short fact using only that quote.
6. If missing: reply "Not in attached sources — add row to SOURCES.md or ask human" — do not guess.

Verify opens the same row and checks the quote matches before send.

</details>
