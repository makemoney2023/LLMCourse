# Workshop facilitator notes: Retrieval & grounding

**Workshop session:** 2  
**Module duration:** ~35 minutes  
**Follows:** Tools & MCP in same session

## Purpose

Learners practice evidence selection and retrieve-then-answer sequencing—reducing hallucination and context bloat.

## Timing

| Segment | Minutes | Activity |
|---------|---------|----------|
| Teach | 8 | Three-way table: instructions vs retrieval vs memory. |
| Demo | 10 | Ungrounded vs grounded answer side-by-side. |
| Exercise 2 | 7 | Trim context pack; groups share cuts. |
| Exercise 1 | 8 | Triads assign three task types. |
| Exercise 3 | 7 | Rewrite vague ask; debrief verify steps. |

## Demo steps

1. Ask a question requiring **internal data** without attachments—show plausible wrong specifics.
2. Repeat with **targeted attach** or search; require citations.
3. Show **over-attach** thread (many files); note latency/context; trim live.
4. Optional: bad RAG chunk—answer cites wrong section; discuss verify.

## Discussion prompts

- "When did retrieval hurt you—too little or too much?"
- "What do you always verify for numbers and dates?"
- "Where do standing instructions mention retrieval without providing the doc?"
- "How does retrieve-then-answer differ from 'search the web and write'?"

## Session 2 close

Synthesize: Session 1 tightened standing context; Session 2 added **capabilities + evidence**. Preview Session 3: threads grow—compaction and memory.

## Materials

- Module diagram (tools/retrieval + window path highlighted)
- Sample over-attach file list (Exercise 2)
- Optional: one-page internal doc for live cite demo
